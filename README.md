# XAI judgment study materials

[Download the complete research materials](IDA2027_Research_Materials.zip). Extract the archive to retain its folder structure, then follow the included README.

The package contains:

- Study interface and five counterbalanced list entry points.
- Fixed stimuli, stimulus exports, and source lists.
- De-identified task responses for 70 participants and questionnaire data.
- Statistical analysis code, pinned dependencies, and saved aggregate outputs.
- Model/explanation notebook and stimulus-building utilities.

The public demonstration disables remote response collection. The analysis uses answer summaries; provenance markers distinguish derived event fields from original event observations.

The manuscript PDF and LaTeX source are maintained separately.
